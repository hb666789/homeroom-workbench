# 班主任工作台（高中）

一个为高中班主任设计的班级管理网页工具，**纯前端、零依赖、开箱即用**，数据保存在浏览器本地。

## 快速开始

双击打开 `index.html` 即可使用（无需安装任何环境）。
如果浏览器对 `file://` 方式存储数据有限制，也可以用任意静态服务器：

```bash
npx serve .          # 或者
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

| 模块 | 说明 |
| --- | --- |
| 📊 总览 | 班级统计卡片、历次考试班级平均分趋势、最近考试各科平均分、总分分布、前十名、需要关注的学生 |
| 👥 学生管理 | 每位学生独立建档：基本信息、**学科情况**（各科水平/态度/作业/薄弱点/备注）、**生活情况**（性格/兴趣/家庭/人际/心理/健康）、成长记录时间线；单个学生的成绩趋势、排名趋势、与班级平均对比雷达图 |
| 📝 成绩管理 | 新建/编辑/删除考试，按考试录入各科成绩，自动计算总分、平均分、排名、班级平均分；低于满分 60% 的分数自动标红 |
| 📈 数据分析 | 班级整体：各科平均分柱状图、总分分布、历次趋势；学生个人：各科趋势、排名趋势、雷达图 |
| ⚙️ 设置 | 班级名称、科目与满分管理、数据导出（JSON 备份）/导入、载入示例数据、清空数据 |

## 数据说明

- 数据保存在浏览器的 **localStorage** 中，请定期在「设置」中**导出 JSON 备份**。
- 首次打开可一键载入示例数据体验全部功能。
- 换电脑或清理浏览器缓存前，务必先导出备份，再在新环境「导入数据」。
