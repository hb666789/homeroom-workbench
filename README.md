# 班主任工作台（高中）

一个为高中班主任设计的班级管理网页工具，**纯前端、零依赖、开箱即用**，数据保存在浏览器本地。

## 快速开始

双击打开 `index.html` 即可使用（无需安装任何环境）。
如果浏览器对 `file://` 方式存储数据有限制，也可以用任意静态服务器：

```bash
npx serve .          # 或者
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

| 模块 | 说明 |
| --- | --- |
| 📊 总览 | **可点击的统计模块**（学生/性别/考试/平均分/及格率/优秀率），点击展开对应详情；班级平均分趋势、各科平均分（占满分百分比）、**性别比例饼图**、**总分分布饼图（百分比）**、前十名、需关注名单 |
| 👥 学生管理 | 每位学生独立建档：基本信息、**学科情况**（各科水平/态度/作业/薄弱点/备注，**支持自定义添加/删除学科**）、**生活情况**（性格/兴趣/家庭/人际/心理/健康）、成长记录时间线；个人成绩趋势/排名/雷达图；**批量选择**：批量编辑、批量移动班级、批量删除 |
| 📝 成绩管理 | 新建/编辑/删除考试，按考试录入成绩并自动计算总分、排名、班级平均分；**试卷题目管理**（逐题添加 + 文本批量导入）；**逐题统计**：点击单元格登记每题对/错/未答，自动统计每题**正确率/错误率**（柱状图 + 汇总饼图） |
| 📈 数据分析 | 班级整体：各科平均分、总分分布、历次趋势；学生个人：各科趋势、排名趋势、与班级平均对比雷达图 |
| 🏫 多班级 | 支持**多个班级**独立管理（学生/考试/成绩互不影响），侧边栏一键切换；设置页可新建/重命名/删除班级 |
| ⚙️ 设置 | 班级管理、科目与满分管理（全局）、数据导出（JSON 备份）/导入、载入示例数据、清空数据 |

## 数据说明

- 数据保存在浏览器的 **localStorage** 中，请定期在「设置」中**导出 JSON 备份**。
- 旧版本（单班级）数据会自动迁移为多班级结构，无需手动处理。
- 首次打开可一键载入示例数据（含两个班级、试卷逐题统计示例）体验全部功能。
- 换电脑或清理浏览器缓存前，务必先导出备份，再在新环境「导入数据」。

## 文件结构

```
homeroom-workbench/
├── index.html          # 页面骨架（含班级切换）
├── css/style.css       # 样式
└── js/
    ├── store.js        # 数据层 v2：多班级 + 试卷题目/逐题统计 + localStorage
    ├── charts.js       # 纯 SVG 图表：折线/柱状/雷达/分布/饼图
    ├── students.js     # 学生管理（批量操作 + 自定义学科）
    ├── grades.js       # 成绩管理（试卷导入 + 逐题统计）
    ├── analysis.js     # 数据分析
    └── app.js          # 应用外壳：总览（交互模块）/设置/导航/弹窗
```
